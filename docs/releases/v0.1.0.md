# v0.1.0

`v0.1.0` is the first public release of `policy-eval-harness`.

It ships the reference methodology core:

- deterministic replay for fixed sequential evaluation universes
- paired evaluation and promotion-gate verdicts
- a fully local synthetic approval-workflow demo
- secondary workflow examples for label comparison and 2x2 ablation analysis
- CI and reproducibility checks for the public contract surface

This release is intentionally scoped as a methodology artifact, not a mature platform claim.

Primary entrypoints:

- `policy-eval demo run --manifest examples/core_demo/demo.yaml --out-dir <dir>`
- `policy-eval workflow label-compare run --manifest examples/label_compare/label_compare.yaml --out-dir <dir>`
- `policy-eval workflow ablation-2x2 run --manifest examples/ablation_2x2/ablation_2x2.yaml --out-dir <dir>`

The expected next action after merge is to tag `v0.1.0`.
